# Maya Steel Works

Responsive, static company website built using HTML, CSS and JavaScript. Business contact information and six core services are based on the supplied company brochure.

## Run

Requires Node.js 20+.

```sh
npm run check
npm run dev
npm run build
```

`npm run dev` serves `public/` at localhost:3000. `npm run build` creates deployable `dist/` files. Vercel is configured via `vercel.json` (Other framework, `npm run build`, `dist` output).

## Features

Industrial-themed mobile-first responsive design; accessible navigation; six service cards; categorized illustrative image gallery; quote review dialog that opens WhatsApp only after user interaction; click-to-call; business hours and area location; printable `/brochure.html`.
